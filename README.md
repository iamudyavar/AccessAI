# AccessAI

https://github.com/user-attachments/assets/29156a9d-b8b4-4f87-86ff-6196478fee1a

AccessAI is an AI-powered tool designed to help developers and organizations create more inclusive and accessible websites. By leveraging Claude 3.5 Sonnet through AWS Bedrock, it seamlessly analyzes your website's code against WCAG guidelines and provides intelligent suggestions that enhance accessibility at every level. With its advanced multimodal capabilities, the app can analyze screenshots to identify visual issues and also provides a unique feature that allows you to simulate various disabilities on your website. Whether you’re refining contrast ratios, enhancing readability, or ensuring inclusivity, AccessAI empowers you to build better web experiences for everyone.
