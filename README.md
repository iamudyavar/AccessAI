# AccessAI
Making websites more accessible


https://github.com/user-attachments/assets/29156a9d-b8b4-4f87-86ff-6196478fee1a

AccessAI is an AI-powered tool designed to help developers and organizations create more inclusive and accessible websites. It provides intelligent code suggestions by analyzing your website’s code against WCAG guidelines and offers feedback to improve accessibility, all powered by Claude 3.5 Sonnet through AWS Bedrock. With its advanced multimodal capabilities, AccessAI analyzes images and screenshots to identify visual issues, and its unique simulation feature allows you to experience your website as users with various disabilities might. Whether you’re refining contrast ratios, enhancing readability, or ensuring inclusivity, AccessAI empowers you to build better web experiences for everyone.
